# AI usage

This project is built by two people with heavy help from an AI coding agent (Claude Code).

- **People decide**: the idea, the name, the rules, the parameters, what gets deployed, what gets submitted.
- **The agent writes**: most of the contract code, tests, scout scripts, the page and these documents, in small reviewed steps.
- **No AI at run time is required**: the scouts and the simulation run on plain scripted strategies with no model calls.

Anything the agent could not verify is marked as such in the README rather than stated as fact.

## Timeline

- **11 Nov 2026:** research and the choice of idea (no code).
- **12 Nov 2026:** the repository was created and the game was built, with the agent working in small steps. That is why the whole history covers hours, not weeks, and why some commits are minutes apart: each finished piece was committed on its own. `RULES.md` came first (the second commit), then the contracts. The replay ran on testnet the same afternoon and the live game started that evening.
- **13 to 14 Nov:** the live game's first rounds, the demo film and the submission.
