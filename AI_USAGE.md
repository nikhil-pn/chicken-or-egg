# AI usage

This project is built by two people with heavy help from an AI coding agent (Claude Code).

- **People decide**: the idea, the name, the rules, the parameters, what gets deployed, what gets submitted.
- **The agent writes**: most of the contract code, tests, scout scripts, the page and these documents, in small reviewed steps.
- **No AI at run time is required**: the scouts and the simulation run on plain scripted strategies with no model calls.

Anything the agent could not verify is marked as such in the README rather than stated as fact.
